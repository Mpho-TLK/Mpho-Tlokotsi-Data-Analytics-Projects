## 1. Consumer Complaints Text Analytics Pipeline

### Overview
An end-to-end text analytics pipeline built on a synthetic consumer complaints dataset, styled on a real-world CFPB-type complaints scenario for a fictional medical aid provider client. The goal was to identify complaint themes and classify complaint text automatically.

### Objective
- Explore and clean a raw text dataset of customer complaints
- Identify recurring themes in complaint text without manual labelling
- Build models to classify complaints automatically

### Methods & Techniques
- **Exploratory Data Analysis (EDA)** — understanding complaint volume, structure, and text characteristics
- **TF-IDF feature engineering** — converting complaint text into numerical features
- **LDA (Latent Dirichlet Allocation) topic modelling** — unsupervised identification of complaint themes
- **Classification modelling** — Logistic Regression and Naive Bayes models to classify complaints

### Tools
Python (pandas, scikit-learn, matplotlib)

### Files
- `notebooks/text_analytics_pipeline.ipynb` — full pipeline: data loading, EDA, TF-IDF, LDA topic modelling, classification models
- `report/text_analytics_report.docx` — written report summarising methodology and findings

### Key Takeaways
Practical experience turning unstructured text into structured insight — from raw complaint text through to a working classification model — and communicating technical findings in a business-report format.

## 2. Statistics & Machine Learning Assignment

### Overview
A summative assignment applying core statistical and machine learning methods to a set of structured problems, combining hand-calculated statistics with applied ML concepts.

### Objective
Demonstrate understanding of foundational statistics and machine learning theory through applied calculation and interpretation.

### Methods & Techniques
- **Bias-variance decomposition** — analysing the trade-off between model bias and variance
- **5-fold cross-validation with Logistic Regression** — evaluating model performance and generalisation
- **Bayes' theorem** — applied probability calculations
- **Gaussian kernel regression** — non-parametric regression modelling
- **Principal Component Analysis (PCA)** — dimensionality reduction

### Tools
Microsoft Excel (calculations), Microsoft Word (written interpretation)

### Files
- `stats-ml-assignment/calculations.xlsx` — worked calculations for all methods above
- `stats-ml-assignment/written_answers.docx` — written interpretation and explanation of results

### Key Takeaways
Hands-on application of statistical and ML theory to concrete problems, with an emphasis on interpreting and explaining results clearly rather than just computing them.
